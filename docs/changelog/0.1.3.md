# stcjudge v0.1.3

Date: 2026-09-16

本版本主要带来完整的发布流水线与桌面版自动更新能力, 仿真核心补上了 Timer2 溢出中断, 项目同时首次声明开源许可. 从 v0.1.2 或更早版本升级的用户请先阅读 Upgrade Notes.

## Highlights

- 打一个 tag 即可发布: CI 在 6 个平台 (linux/macos/windows 各 x86_64 与 aarch64) 构建, 校验并打包, 生成 SHA256SUMS, 并按 tag annotation 创建 GitHub Release.
- 桌面版支持自动更新: 启动静默检查, 下载带 SHA256 校验, 按平台替换, 完成后停在 "等待重启" 由你决定何时生效.
- `stcjudge --version` 与桌面版顶栏显示真实构建版本, 不再是固定的包版本号.
- 桌面版补齐日常使用设施: 单实例, 窗口大小记忆, 数据目录与设置持久化, 日志轮转, Ctrl+C 优雅退出.
- 仿真核心新增 Timer2 溢出中断支持.

## Breaking Changes

- 项目首次声明开源许可为 AGPL-3.0-or-later, 分发本项目或其修改版时需要按该许可提供对应源码. 迁移方式: 升级前确认你的分发方式符合 AGPL-3.0-or-later, 若有商业使用需求请另行联系维护者.

## Upgrade Notes

1. 旧版 Release 产物的命名方式与新流程不同, 自动更新只在安装了本版本 (v0.1.3) 的产物之后才可用.
2. 首次启动桌面版会在系统应用数据目录下创建 `stcjudge-gui` 目录, 内含 `settings.json` 与 `logs/`, 不需要手动准备; 旧版设置文件会按结构版本自动迁移.
3. 验证升级: 命令行执行 `stcjudge --version` 应输出 `stcjudge v0.1.3`; 桌面版顶栏右侧显示同一版本号, 且更新入口可用.

## Features

- 发布流程: 分支, PR, tag 与手动触发共用同一套 CI, 只有 tag 发布会创建 Release, 手动发布可指定已有 tag; 产物命名统一为 `<名称>-<版本>-<平台>-<架构>.<扩展名>`.
- CLI 与桌面版: 构建版本通过 `PROJECT_BUILD_VERSION` 注入, tag 构建显示 `v1.2.3`, 非 tag 构建追加 7 位短 hash, 工作区有未提交改动时用 `^` 分隔; 日常 `cargo` 构建显示 `dev-build`.
- 桌面版自动更新: 启动静默检查与手动检查, 按平台匹配资产, 支持断点续传与 SHA256 校验, Linux 与 Windows 就地替换并在失败时回滚, macOS 生成脱离进程的替换脚本; 可以跳过指定版本, 也可以关闭启动自动检查.
- 桌面版窗口: 同一数据目录只允许一个实例, 二次启动会把命令行参数转发给已有实例并唤起窗口; 记住非全屏, 非最大化时的窗口大小与最大化标志, 全屏尺寸不会覆盖普通尺寸.
- 桌面版数据: 数据目录与主日志路径可用 `STCJUDGE_GUI_DATA_DIR` 与 `STCJUDGE_GUI_LOG_FILE` 覆盖, 日志按天与单文件大小轮转并限制留存数量, 设置文件带结构版本号与迁移逻辑.
- 桌面版退出: Ctrl+C, 关闭窗口与更新交接都汇入同一个优雅退出路径, 停止后台服务, 释放单实例锁并刷盘日志.
- GUI: 支持把 `.hex` 与 `.rhai` 文件拖入窗口直接加载, 并自动切到对应标签页.
- 仿真核心: Timer2 溢出可作为固定低优先级中断源进入 `0x0063` 向量, 支持 ET2 门控, 以及固件关闭 ET2 时清除挂起请求的语义.
- 构建: 新增 `just dist` (当前平台的发布产物), `just fake-dist` (版本号为 v0.0.0 的端到端更新测试构建) 与 `just debug` (使用隔离数据目录的调试实例).

## Bug Fixes

- 桌面版: 版本号与更新入口原先贴在窗口底部, 在部分环境会被窗口底边裁切, 现改为顶栏右侧固定展示.
- 桌面版: 恢复上次窗口尺寸时会按屏幕可用区域夹取, 避免窗口底部藏到 Dock 后面或落到屏幕之外.
- Windows 打包: 修正清理暂存目录时误用通配符导致的 CI 失败.
- GUI: UART 文本改为按字符换行并关闭两端对齐, 避免输出错位.
