## 为什么只归档不建 sample

- 这些届次还没有统一到 IAP15F2K61S2 + 四梯平台, 与本仓库仿真器的目标平台不一致.
- 没有找到与它们配套的满分代码, 也就无法像 `samples/` 里那样"按原题写评测脚本, 再用满分代码验证".
- 归档的目的是保持"各届原题"这条线的完整性, 后续若拿到对应届次的代码与平台资料, 可以随时从这里起手补 sample.
