# PA13-2 第十三届蓝桥杯单片机省赛第二场 (大学组)

题目原文见 [problem/13P_P2_单片机程序设计（大学组）.pdf](problem/13P_P2_单片机程序设计（大学组）.pdf), 程序设计部分 85 分.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为 BTN 独立按键模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 通过 PCF8591 的 ADC 通道测量电位器 RB2 的输出电压.
- 通过超声波传感器测距, 声速按 340m/s (25 摄氏度) 计算.
- 数码管显示电压, 距离与电压参数.
- 按键完成界面切换与参数设置.
- LED 指示灯指示当前界面与测量状态, 并通过 PCF8591 的 DAC 输出距离对应的电压.

## 显示格式

| 界面 | 提示符 | 内容 | 示例 |
| --- | --- | --- | --- |
| 电压界面 | `U` | 3 位数码管显示电压, 保留 2 位小数 | `U    2.45` |
| 参数界面 | `P` | 上限参数与下限参数, 各占 2 位数码管, 1 位小数 | `P  4.5 0.5` |
| 测距界面 (连续测量) | `L` | 3 位数码管显示距离, 不足 3 位时高位熄灭 | `L     46` |
| 测距界面 (未启动测量) | `L` | 固定显示 `AAA` | `L    AAA` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 界面键, 按 电压界面 -> 测距界面 -> 参数界面 的顺序循环切换 |
| `S5` | 参数界面下选择上限参数或下限参数 |
| `S6` | 当前选择的电压参数增加 0.5V |
| `S7` | 当前选择的电压参数减少 0.5V |

其它要求:

- 按键做消抖处理, 一次按键只触发一次.
- 按键动作不影响数码管显示与数据采集.
- 电压参数在参数调整过程中无效, 通过 `S4` 退出参数界面时生效.
- 从测距界面进入参数界面时, 默认选择电压上限参数.
- 参数范围为 0.5V 到 5.0V, 到边界后循环: 加 5.0V 后回到 0.5V, 减 0.5V 后回到 5.0V.

## 超声波测距与 DAC

- 电压下限参数 < VRB2 < 电压上限参数 时启动连续测距, 否则测距停止, 测距界面固定显示 `AAA`.
- 测距启动时, DAC 输出电压与距离的关系见图 8: 20cm 对应 1.0V, 80cm 对应 5.0V.
- 测距未启动时 DAC 输出 0V.

## LED 指示灯

| 指示灯 | 行为 |
| --- | --- |
| `L1` | 电压界面下点亮, 其余界面熄灭 |
| `L2` | 测距界面下点亮, 其余界面熄灭 |
| `L3` | 参数界面下点亮, 其余界面熄灭 |
| `L8` | 启动连续测量期间以 0.1 秒为间隔切换亮灭, 停止时熄灭 |
| 其余指示灯 | 保持熄灭 |

## 初始状态

- 处于电压界面.
- 电压上限参数为 4.5V, 下限参数为 0.5V.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 测距精度 | <= ±3cm |
| 按键动作响应时间 | <= 0.2s |
| 指示灯动作响应时间 | <= 0.1s |

## 满分代码

- `src/driver/`: 数码管, 按键, LED, IIC 与超声波驱动.
- `src/user/main.c`: 界面状态机, 参数管理, 测距启动判断与 DAC 输出.
- `prj/pa13-2.uvproj`: Keil 工程, 文件路径已改到本仓库的相对布局, 输出名为 `pa13-2`.
- `prj/Objects/pa13-2.hex`: 满分代码的编译产物, 也是评测脚本的输入.

代码取自 4T 可测评场次的满分代码, 只做目录搬迁, 未改动逻辑.

## 评测脚本

`judge/full.rhai` 按题目原文推导, 共 9 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 上电处于电压界面, 只有 `L1` 点亮, 测距未启动时 DA 输出 0V | 4.6, 4.7, 4.8 |
| 2 | 电压界面显示两位小数电压, 读数与实际电压一致 | 4.3-1 |
| 3 | `S4` 循环切换三个界面, 界面指示灯同步, 每次按键 0.2s 内完成 | 4.2-2, 4.4-1, 4.6-1 |
| 4 | 电压在上下限之间时启动测距并显示距离 (±3cm), 超限时显示 `AAA`, 回到区间后恢复 | 4.2-1, 4.3-3, 4.5 |
| 5 | 参数界面上下限显示, `S6`/`S7` 加减 0.5V, `S5` 切换选择, 5.0V 与 0.5V 循环 | 4.3-2, 4.4-1 |
| 6 | 参数在参数界面内不生效, 退出参数界面后立即生效 (测距停止, DA 回到 0V) | 4.4-1 说明 1 |
| 7 | 测距期间 `L8` 按 0.1s 闪烁, 停止后熄灭 | 4.2-3, 4.6-2 |
| 8 | DAC 输出: 20cm 为 1.0V, 80cm 为 5.0V, 中间单调不减, 未启动为 0V | 4.7 |
| 9 | 响应时间: 按键动作响应 <= 0.2s, 指示灯动作响应 <= 0.1s (实测 10ms / 0ms) | 4.2 性能要求 |

运行方式:

```shell
just judge-sample pa13-2
```

当前回归结果: **9 项全部通过**.

## 备注

- 采样实现的测距读数比设定距离大 1cm (例如设定 45cm 显示 46), 在题目的 ±3cm 精度要求之内; 评测脚本按 ±3cm 判定.
- 图 8 给出的是 20cm 到 80cm 的直线关系, 采样实现按 15cm 一级把输出电压量化为整数伏 (20cm 1.0V, 35cm 2.0V, 50cm 3.0V, 65cm 4.0V, 80cm 5.0V), 与直线只在 20/35/50/65/80cm 处重合. 评测脚本因此按图 8 的两个端点 (20cm, 80cm) 加单调性判定, 不对中间点做严格线性断言.
- `L8` 实测为 0.1s 亮与 0.1s 灭交替; 评测脚本按 10ms 采样 600ms, 要求出现至少 4 次跳变.
- 电压条件失效到测距停止 (显示 `AAA` 且 `L8` 熄灭) 实测约 0.29s, 覆盖了 ADC 采样节拍; 评测脚本等待 0.5s 后断言.
