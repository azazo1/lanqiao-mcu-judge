# PA15-2 第十五届蓝桥杯单片机省赛 (第二次, 大学组)

题目原文见 [problem/15 第十五届省赛（第二次）题目_程序题.pdf](problem/15%20第十五届省赛（第二次）题目_程序题.pdf) (有文本层, 直接读取, 无需 OCR); 同目录另有米醋工作室的界面流转与考察重点两份文档.

同一届省赛的第一次见 [../pa15/](../pa15/README.md) (NE555 频率测量与校准), 两场题目完全不同.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为矩阵键盘 (KBD) 模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- DS18B20 测量环境温度, 最终温度 = 测量值 + 温度校准值 (校准值可为负).
- 连续两次采样的温度上升或下降幅度超过 1 摄氏度时触发温度突变报警.
- PCF8591 输出 DAC, 支持温度控制与手动控制两种模式.
- 数码管显示温度, DAC 输出控制与校准值三个界面.
- 按键完成界面切换, 参数调整, DAC 模式切换, 继电器锁定与通断控制.

## 显示格式

| 界面 | 内容 | 示例 |
| --- | --- | --- |
| 温度界面 | 界面编号 `C` + 温度整数 | `C     24` |
| DAC 输出控制界面 | 界面编号 `A` + DAC 数字量 (3 位, 高位熄灭) | `A    100` |
| 校准值界面 | 界面编号 `P` + 校准值 (整数, 可为负) | `P      2` / `P     -9` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S12` | 循环切换 温度界面 -> DAC 输出控制界面 -> 校准值界面 |
| `S16` | DAC 界面下数字量加 5; 校准值界面下校准值加 1; 温度界面下且解锁时打开继电器 |
| `S17` | DAC 界面下数字量减 5; 校准值界面下校准值减 1; 温度界面下且解锁时关闭继电器 |
| `S13` 短按 | 切换 DAC 输出控制模式 (温度控制 / 手动控制) |
| `S13` 长按 | 按住超过 1.5 秒后松开, 切换继电器锁定与解锁状态 |

- 校准值在退出校准值界面时生效.
- 锁定状态下 `S16`, `S17` 对继电器的控制无效.
- DAC 数字量范围 0-255, 校准值范围 -9 摄氏度到 9 摄氏度.

## DAC 输出

| 模式 | 输出 |
| --- | --- |
| 温度控制 | 与温度成直线: 10 摄氏度对应 2V, 40 摄氏度对应 5V |
| 手动控制 | 由 DAC 数字量决定, 与温度无关 |

## LED 指示灯

| 指示灯 | 行为 |
| --- | --- |
| `L1` | 温度控制模式下点亮, 否则熄灭 |
| `L2` | 温度上升报警, 触发后持续点亮 2 秒 |
| `L3` | 温度下降报警, 触发后持续点亮 2 秒 |
| `L4` | 温度突变报警, 以 0.2 秒为间隔闪烁, 持续 3 秒后熄灭 |
| `L8` | 继电器解锁状态下点亮 |
| 其余 | 保持熄灭 |

## 初始状态

- 温度界面.
- 继电器解锁状态, DAC 处于温度控制模式.
- DAC 输出数字量默认值 100, 温度校准值默认值 0.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 按键动作响应时间 | <= 0.1s |
| 温度采样频率 | <= 1s |
| 指示灯动作响应时间 | <= 0.1s |

- `src/user/main.c`: 界面状态机, 温度校准与突变判断, DAC 双模式, 继电器锁定与报警指示灯逻辑.

- `prj/Objects/pa15-2.hex`: 编译产物, 也是评测脚本的输入.

## 评测脚本

`judge/full.rhai` 按题目原文推导, 共 7 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 温度界面整数读数, `L1` 与 `L8` 点亮, 25 摄氏度时 DAC 输出 3.5V | 3.5-1, 3.8, 四 |
| 2 | DAC 温度控制三点: 10 摄氏度 2V, 25 摄氏度 3.5V, 40 摄氏度 5V | 3.4 |
| 3 | 校准值加减 1 与退出界面后生效 (30 摄氏度加 2 度校准后 DAC 提高约 200mV) | 3.3, 3.5-3, 3.6 |
| 4 | 手动模式下 `A` 界面显示 DAC 数字量 (默认 100, `S16`/`S17` 加减 5) 且输出与温度无关 | 3.4, 3.5-2, 3.6 |
| 5 | 解锁时 `S16`/`S17` 控制继电器, 长按 `S13` 锁定后无效, 再长按解锁后恢复 | 3.6, 3.7, 3.8-3 |
| 6 | 上升报警 `L2` 亮 2 秒后熄灭, 下降报警 `L3` 点亮, 温度突变时 `L4` 闪烁 | 3.3, 3.8-2 |
| 7 | 响应时间: 按键 <= 0.1s, 指示灯动作 <= 0.1s, 温度采样刷新 <= 1s (实测 0ms / 0ms / 860ms) | 3.2 |

运行方式:

```shell
just judge-sample pa15-2
```

当前回归结果: 6 项通过, 1 项失败 (第 6 项中的 `L4` 子项, 见下).

## 评测脚本发现的实现问题

- 温度控制模式下 DAC 输出控制界面显示的不是 DAC 数字量参数值. 题目 3.5-2 要求该界面显示 DAC 数字量, 初始状态又规定数字量默认为 100; 实测在温度控制模式下 25 摄氏度时该界面显示 `A    178`, 正是当前输出对应的数字量 (3.5V 对应 178), 而不是 100. 切到手动控制模式后显示恢复为可调的数字量 (100 -> 105 -> 95), 说明该界面在温度控制模式下显示的是当前输出值.
- 温度突变报警 `L4` 只在第一次突变时触发 (第 6 项). 单独验证: 设备先稳定在 15 摄氏度, 再跳到 35 摄氏度, `L4` 会按要求以 0.2 秒亮 / 0.2 秒灭的节奏闪烁约 3 秒后自动熄灭 (实测 6 秒采样序列 `000000000000001100110011001100110011001100000000000000000000`), 说明闪烁功能本身实现正确. 但在评测脚本的场景里 (先由 20 摄氏度升到 25 摄氏度, 再降到 15 摄氏度, 然后跳到 35 摄氏度), 连续观察 6 秒以上 `L4` 始终为灭, 即后续的突变不再触发报警. 题目 3.3 要求"连续的两次温度采样结果上升或下降幅度超过 1 摄氏度"就立即触发, 因此该实现对连续多次突变的处理与题目仍有出入.

其余实测与题目一致: 温度显示与校准值生效, 温度控制模式的三点输出, 手动模式数字量加减与输出, DAC 模式指示灯 `L1`, 继电器锁定/解锁与按键控制, 上升/下降报警指示灯.

## 备注

- DAC 输出量化步进约 20mV, 评测脚本对输出差值按 ±40mV 判定.
- 采样实现的温度上升/下降报警在每一次采样变化时都会触发, 上电升温过程中 `L2` 也会点亮, 属于题目 3.8-2 的"温度上升时触发"范围.
