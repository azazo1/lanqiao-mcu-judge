# PA14 第十四届蓝桥杯单片机省赛 (本科组)

题目原文是图片: [problem/原题图片/](problem/原题图片/) 是五页题目截图, 已用本地 Apple Vision OCR 转成 [problem/题目OCR文本.txt](problem/题目OCR文本.txt), 本样例的题目整理与评测点推导均以该 OCR 文本为准.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为矩阵键盘 (KBD) 模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 通过 PCF8591 的 ADC 通道测量光敏电阻分压, 判断环境亮暗状态.
- 通过 DS1302 获取时间数据, 通过 DS18B20 获取环境温度数据.
- 通过 P34 引脚测量 NE555 脉冲频率, 并换算成湿度数据.
- 数码管显示, 按键切换界面与设置参数, LED 指示灯输出指示.

## 频率与湿度

- 200Hz 对应 10% 湿度, 2000Hz 对应 90%, 中间线性换算.
- 测量频率不在 200Hz - 2000Hz 范围内时视为无效数据, 温湿度界面的湿度位置以非数字标记显示, 且不计入回显统计.

## 显示格式

| 界面 | 内容 | 示例 |
| --- | --- | --- |
| 时间界面 | 时, 分, 秒各 2 位, `-` 分隔, 不足补 0 | `13-03-05` |
| 温度回显 | 标识符 `C` + 最大温度 + `-` + 平均温度 (1 位小数) | `C28-23.2` |
| 湿度回显 | 标识符 `H` + 最大湿度 + `-` + 平均湿度 (1 位小数) | `H68-50.4` |
| 时间回显 | 标识符 `F` + 触发次数 (2 位, 左侧补 0) + 时 + `-` + 分 | `F0213-03` |
| 参数界面 | 标识符 `P` + 温度参数 | `P     30` |
| 温湿度界面 | 标识符 `E` + 温度整数 + `-` + 湿度整数 | `E  23-50` |

触发次数为 0 时, 时间回显的时, 间隔与分熄灭, 温度与湿度回显除界面标识符外其余位熄灭.

## 采集触发

- 环境由亮变暗时触发一次温度与湿度采集, 数码管立刻切到温湿度界面显示本次数据.
- 触发后 3 秒内不可重复触发, 3 秒后返回触发前的界面.
- 采集期间所有按键操作无效.

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 循环切换 时间界面 -> 回显界面 -> 参数界面 |
| `S5` | 回显界面下切换 温度回显/湿度回显/时间回显 (时间界面下无效), 每次从时间界面进入回显界面默认温度回显 |
| `S8` | 参数界面下温度参数加 1 |
| `S9` | 参数界面下温度参数减 1; 时间回显子界面下长按超过 2 秒清除记录, 触发次数归零 |

## LED 指示灯

| 指示灯 | 行为 |
| --- | --- |
| `L1` | 时间界面下点亮 |
| `L2` | 回显界面下点亮 |
| `L3` | 温湿度界面下点亮 |
| `L4` | 采集温度大于温度参数时以 0.1 秒为间隔闪烁 |
| `L5` | 湿度数据无效时点亮, 直到下次采集到有效数据 |
| `L6` | 与上次采集相比 (触发次数不少于 2) 温度与湿度均升高时点亮 |
| 其余 | 保持熄灭 |

## 初始状态

- 处于时间界面.
- 温度参数 30 摄氏度.
- 触发次数 0.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 频率测量精度 | ±8% |
| 按键动作响应时间 | <= 0.2s |
| 指示灯动作响应时间 | <= 0.1s |
| 亮暗状态变化感知时间 | <= 0.5s |

## 满分代码

- `src/driver/`: 数码管, 按键, LED, IIC, DS1302, DS18B20 与初始化驱动.
- `src/user/main.c`: 界面状态机, 频率湿度换算, 亮暗检测与采集触发, 回显统计与指示灯逻辑.
- `prj/pa14.uvproj`: Keil 工程, 文件路径已改到本仓库的相对布局, 输出名为 `pa14`.
- `prj/Objects/pa14.hex`: 编译产物, 也是评测脚本的输入.

代码取自上游的第十四届省赛新版满分代码包, 只做目录搬迁.

## 评测脚本

`judge/full.rhai` 按 OCR 后的题目原文推导, 共 6 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 时间界面显示设置的时分秒, `L1` 点亮; 触发次数 0 时三个回显子界面只显示标识符; 参数默认 30 | 3.4, 3.7-1, 四 |
| 2 | 亮转暗触发采集并切到温湿度界面, 3 秒后返回; 1100Hz/200Hz/2000Hz 对应 50%/10%/90% 湿度 | 3.3, 3.4-4, 3.5 |
| 3 | 频率超出 200-2000Hz 时湿度无效: `L5` 点亮且湿度位置不是数字 | 3.3, 3.7-2 |
| 4 | 回显统计最大与平均温湿度, 时间回显记录触发次数与最近触发时间, 长按 `S9` 清零 | 3.4-2, 3.6-1 |
| 5 | 按键作用范围: `S5` 仅在回显界面有效, 参数界面下 `S5` 不换页 | 3.6 |
| 6 | `L4` 温度超参数时 0.1s 闪烁, `L6` 两次采集温湿度均升高时点亮, `L7`/`L8` 熄灭 | 3.7-2 |

运行方式:

```shell
just judge-sample pa14
```

当前回归结果: 6 项全部通过. 这是目前少数几份与题目逐条一致的实现 (前几轮的社区素材都查出过问题).

## 备注

- 采样实现的 DS1302 会在启动阶段写入初始时间, 评测脚本在启动初始化完成之后再 `set_rtc`, 否则设置会被覆盖.
- 光照方向按实测定标: 光敏分压 4.0V 视为亮, 0.5V 视为暗, 亮转暗时触发采集.
- 采集触发有 3 秒锁定, 评测脚本在相邻两次触发之间等待 3.2 秒, 否则第二次亮转暗会被丢弃.
- 湿度无效时的替代字符在题目图片上 OCR 出来是 `FR`, 采样实现显示的是 `AA`, 两者对不上; 由于扫描质量不足以确认原字符, 评测脚本只断言该位置不是数字并且 `L5` 点亮, 待拿到清晰原题后补齐.
- 温湿度界面 (采集触发期间) 采样实现保留了时间界面的 `L1`, 与题目 "时间界面下点亮, 否则熄灭" 的表述有出入; 该行为未纳入断言, 一并待确认.
