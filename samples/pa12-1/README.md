# PA12-1 第十二届蓝桥杯单片机省赛第一场

题目原文见 [problem/12届_单片机_程序设计.pdf](problem/12届_单片机_程序设计.pdf), 程序设计部分 70 分.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为 KBD 模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 通过 DS18B20 测量温度.
- 通过 PCF8591 完成 DAC 输出.
- 数码管显示温度, 参数与 DAC 电压.
- 按键完成界面切换, 参数调整与模式切换.
- LED 指示当前模式与当前界面.

## 显示格式

| 界面 | 标识位 | 内容 | 示例 |
| --- | --- | --- | --- |
| 温度界面 | `C` | 温度, 保留 2 位小数, 单位摄氏度 | `C   24.25` |
| 参数界面 | `P` | 温度参数, 整数, 单位摄氏度 | `P     25` |
| DAC 界面 | `A` | DAC 输出电压, 保留 2 位小数 | `A    3.25` |

标识位占最左侧一位, 数值占右侧若干位, 中间位熄灭.

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 界面键, 按 温度界面 -> 参数界面 -> DAC 界面 的顺序循环切换 |
| `S8` | 减键, 仅在参数界面有效, 参数减 1 |
| `S9` | 加键, 仅在参数界面有效, 参数加 1 |
| `S5` | 模式键, 在模式 1 与模式 2 之间切换 |

其余要求:

- 按键做消抖处理, 一次按键动作只触发一次.
- 按键动作不影响数码管显示与数据采集.
- 温度参数在退出参数界面时生效.

## DAC 输出

- 模式 1: 实时温度小于温度参数时输出 0V, 否则输出 5V.
- 模式 2: 按图 7 给出的关系输出电压, 环境温度 20 度对应 1.0V, 40 度对应 4.0V, 中间线性, 即 $V = 1.0 + 0.15 \times (T - 20)$.

## LED 指示灯

| 指示灯 | 点亮条件 |
| --- | --- |
| `L1` | 当前处于模式 1 |
| `L2` | 当前处于温度界面 |
| `L3` | 当前处于参数界面 |
| `L4` | 当前处于 DAC 界面 |

## 初始状态

- 处于温度界面.
- 处于模式 1.
- 温度参数为 25 摄氏度.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 温度数据刷新时间 | <= 1s |
| DAC 输出电压刷新时间 | <= 0.5s |
| 按键动作响应时间 | <= 0.2s |

## 满分代码

- `src/driver/`: 数码管, 按键, LED, DS18B20, IIC 与初始化驱动.
- `src/user/main.c`: 界面状态机, 参数管理与 DAC 输出.
- `prj/pa12-1.uvproj`: Keil 工程, 文件路径已改到本仓库的相对布局, 输出名为 `pa12-1`, 重新编译会覆盖原来的 hex.
- `prj/Objects/pa12-1.hex`: 满分代码的编译产物, 也是评测脚本的输入.

代码取自 4T 可测评场次的满分代码, 只做目录搬迁, 未改动逻辑.

## 评测脚本

`judge/full.rhai` 按题目原文推导, 共 9 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 上电初始状态为温度界面, 模式 1, 参数 25 度, `L1`/`L2` 点亮 | 4.5, 4.6 |
| 2 | 温度界面显示 `C` 与两位小数温度, 1s 内刷新 | 4.2-1, 4.3-1 |
| 3 | `S4` 循环切换三个界面, 界面指示灯同步, 一次按键只切换一次 | 4.3, 4.4-1, 4.5 |
| 4 | 参数界面 `S9` 加 1, `S8` 减 1, 且在温度界面按键无效 | 4.4-1, 4.4-2 |
| 5 | 模式 1 下温度低于参数输出 0V, 参数下调并退出参数界面后输出 5V | 4.4-1 |
| 6 | 模式 2 下 20 度 1.0V, 30 度 2.5V, 40 度 4.0V, `S5` 切换时 `L1` 同步 | 4.4-1, 4.5-1 |
| 7 | DAC 界面显示 `A` 与两位小数电压, 温度变化后 0.5s 内刷新 | 4.2-2, 4.3-3 |
| 8 | 按键按下后 200ms 内完成界面切换 | 4.2-3 |
| 9 | 数据刷新时间: 温度刷新 <= 1s, DAC 输出电压刷新 <= 0.5s (实测均在 20ms 内) | 性能要求 |

DAC 为 8 位输出, 电压按 5V 满量程换算, 断言留有余量以覆盖量化误差.

运行方式:

```shell
just judge-sample pa12-1
```

当前回归结果: **9 项全部通过**.

## 备注

- 题目中 DAC 界面的标识符是 `A`, 仿真器原来的段码解码表没有 `A` (段码 `0x77`), 已补充到默认解码表.
- 模式 2 在图示区间 (20 度到 40 度) 之外没有给出定义, 评测脚本只在该区间内取点.
