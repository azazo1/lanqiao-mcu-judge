# PA10 第十届蓝桥杯单片机省赛

题目原文见 [problem/10 第十届省赛题目_程序题.pdf](problem/10%20第十届省赛题目_程序题.pdf) (有文本层, 直接读取); 同目录另有米醋工作室的界面流转与考察重点文档.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式 J5 配置为 BTN 独立按键模式.
- 扩展方式 J13 配置为 IO 模式.
- 频率测量要求把竞赛板 J3-SIGNAL 与 P34 短接.

## 功能

- 通过 PCF8591 测量电位器 RB2 输出的模拟电压, 并通过其 DAC 功能输出.
- 通过 P34 测量 NE555 模块输出的频率信号.
- 数码管与 LED 完成数据呈现与状态指示.

## 显示格式

| 界面 | 内容 | 示例 |
| --- | --- | --- |
| 频率显示界面 | 提示符 `F` + 频率值 (6 位, 未使用的高位熄灭) | `F   6000` |
| 电压显示界面 | 提示符 `U` + 电压值 (保留 2 位小数) | `U    3.41` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 在电压测量界面与频率测量界面之间切换 (上电默认电压测量界面) |
| `S5` | 切换 DAC 输出模式: 跟随电位器 RB2 输出电压, 或固定输出 2.0V |
| `S6` | 打开或关闭 LED 指示灯指示功能 (关闭时所有指示灯熄灭) |
| `S7` | 打开或关闭数码管显示功能 (关闭时所有数码管熄灭) |

## DAC 与 LED

- DAC 输出模式: 跟随模式下输出与 VRB2 一致, 固定模式下输出 2.0V.
- `L1` 电压测量界面点亮, `L2` 频率测量界面点亮.
- `L3` 按 VRB2 区间变化: `<1.5V` 熄灭, `1.5-2.5V` 点亮, `2.5-3.5V` 熄灭, `>=3.5V` 点亮.
- `L4` 按频率区间变化: `<1KHz` 熄灭, `1-5KHz` 点亮, `5-10KHz` 熄灭, `>=10KHz` 点亮.
- `L5` 在 DAC 固定输出 2.0V 时熄灭, 跟随模式时点亮.
- 其余指示灯熄灭.

## 初始状态

- 电压测量界面, 数码管显示与 LED 指示功能启用.
- DAC 输出固定电压 2.0V.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 电压数据刷新时间 | <= 0.5s |
| 频率数据刷新时间 | <= 1s |

## 满分代码

- `src/driver/`: 数码管, 按键, LED, IIC (PCF8591) 与初始化驱动.
- `src/user/main.c`: 界面状态机, 电压与频率采集, DAC 模式切换, 数码管与 LED 开关, 区间指示逻辑.
- `prj/pa10.uvproj`: Keil 工程, 输出名为 `pa10` (原工程名 `demo`).
- `prj/Objects/pa10.hex`: 编译产物, 也是评测脚本的输入.

代码来自米醋工作室的第十届省赛工程, 采集时只改了工程输出名.

## 评测脚本

`judge/full.rhai` 按题目原文推导, 共 7 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 上电处于电压界面并显示两位小数电压, `L1` 点亮, DAC 固定输出 2.0V | 4.2-2, 4.4-1, 4.5 |
| 2 | `S4` 切到频率界面, 6 位显示且高位熄灭, `L2` 点亮 (600/500/12000Hz 三点) | 4.2-1, 4.4-2 |
| 3 | `S5` 在固定 2.0V 与跟随 RB2 之间切换, 跟随模式下 DAC 随电位器变化, `L5` 指示 | 4.3-2, 4.4-5 |
| 4 | `S6` 关闭 LED 指示功能后全部熄灭, 再按恢复 | 4.3-3 |
| 5 | `S7` 关闭数码管显示功能后全部熄灭, 再按恢复显示 | 4.3-4 |
| 6 | `L3` 按电压区间变化, `L4` 按频率区间变化 (各取三点) | 4.4-3, 4.4-4 |
| 7 | 数据刷新时间: 电压不超过 0.5 秒, 频率不超过 1 秒 | 4.1-4 |

运行方式:

```shell
just judge-sample pa10
```

当前回归结果: 6 项通过, 1 项失败 (第 7 项, 见下).

## 评测脚本发现的实现问题

- 电压数据刷新时间略超题目上限 (第 7 项). 题目 4.1-4 要求电压数据刷新时间不超过 0.5 秒; 实测把电位器从 3.41V 改到 2.00V 后, 数码管用 520ms 才更新到 `U    2.00`, 超出上限 20ms. 这一项用轮询测量, 因此失败信息里带着实测耗时; 之前用 `run_to` 时只看到"超时", 无法判断是显示不收敛还是真的慢, 现在可以确认显示会收敛, 只是比 0.5 秒慢一点.

## 备注

- 采样实现对电压与频率都做了滑动滤波, 改变输入后需要多个刷新周期才稳定, 评测脚本的采集等待量取 2.5 秒.
- 观察到一个未纳入断言的现象: 电位器固定在 3.41V 时, 电压界面的读数会周期性地在 `3.41` 与 `2.50` 之间交替 (实测序列 `3.41 -> 2.50 -> 2.50 -> 2.50 -> 3.41 -> 2.50`). 已定位: 仿真器的 PCF8591 模型是符合手册的 (一次读返回上一次转换结果, 上电初值 `0x80` 即 2.51V, 并有单测覆盖这条语义), 而固件 `Ad_Read` 在写控制字节 `0x43` 之后只读一次, 所以有时会把上一次的转换值当作本次结果显示出来 —— 也就是说这是固件读取方式的表现, 不是仿真器缺口. 由于题目 4.3-4 只要求 `S7` 控制显示开关, 该现象不影响本检查点的判定.
- 关闭数码管后没有内容可读, 评测脚本改用 `seg_pattern` 判定 8 位数码管是否全部熄灭.
