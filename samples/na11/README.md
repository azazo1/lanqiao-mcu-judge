# NA11 第十一届蓝桥杯单片机国赛

题目原文见 [problem/第十一届决赛单片机设计与开发（第二部分）.pdf](problem/第十一届决赛单片机设计与开发（第二部分）.pdf), 程序设计部分 70 分.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为 KBD 键盘模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 读取 DS1302 的时, 分, 秒寄存器完成时钟功能.
- 通过 AD 转换判断光敏电阻的亮, 暗状态.
- 数码管显示时间, 温度, 亮暗状态与三组参数.
- 按键完成界面切换与参数调整.
- LED 指示灯完成时间窗口, 温度与亮暗状态的指示.

## 显示格式

| 界面 | 标识 | 内容 | 示例 |
| --- | --- | --- | --- |
| 时间数据 | 无 | 时, 分, 秒各 2 位, `-` 分隔, 不足补 0 | `20-20-01` |
| 温度数据 | `C` | 温度, 保留 1 位小数 | `C    33.2` |
| 亮暗状态 | `E` | 分压结果 (2 位小数) 与状态位, 0 表示亮, 1 表示暗 | `E  0.32   1` |
| 时间参数 | `P` + 编号 `1` | 小时参数, 范围 00-23 | `P1     17` |
| 温度参数 | `P` + 编号 `2` | 温度参数, 范围 00-99 | `P2     25` |
| 指示灯参数 | `P` + 编号 `3` | LED 编号, 范围 4-8 | `P3      4` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 数据界面与参数界面之间切换 (进入参数界面默认时间参数, 回数据界面默认时间数据) |
| `S5` | 数据界面下切换 时间/温度/亮暗状态, 参数界面下切换 时间参数/温度参数/指示灯参数 |
| `S8` | 当前参数减 1 |
| `S9` | 当前参数加 1 |

其它要求: 按键消抖; 按键不影响显示与采集; 约束参数边界; 所有参数在退出参数界面时生效, 调整过程中不生效.

## LED 指示灯

| 指示灯 | 行为 |
| --- | --- |
| `L1` | 当前时间处于 小时参数 至下一个 08:00:00 之间时点亮 |
| `L2` | 温度数据小于温度参数时点亮 |
| `L3` | 暗状态持续超过 3 秒点亮, 亮状态持续超过 3 秒熄灭 |
| 指示灯参数指定的 LED | 暗状态时点亮, 亮状态时熄灭 |
| `L4`-`L8` 中未被指定的 | 保持熄灭 |

## 初始状态

- 处于数据界面并显示时间数据.
- RTC 上电默认时间 16 时 59 分 50 秒.
- 时间参数 17, 温度参数 25, 指示灯参数 4.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 温度数据刷新时间 | <= 1s |
| 亮暗状态刷新时间 | <= 0.5s |
| 按键动作响应时间 | <= 0.2s |

## 满分代码

- `src/driver/`: 数码管, 按键, LED, IIC, DS1302, DS18B20 与初始化驱动.
- `src/user/main.c`: 界面状态机, 参数管理, 亮暗判断, 指示灯与时间窗口逻辑.
- `prj/na11.uvproj`: Keil 工程, 文件路径已改到本仓库的相对布局, 输出名为 `na11`.
- `prj/Objects/na11.hex`: 编译产物, 也是评测脚本的输入.

该代码来自上游的社区实现, 未经 4T 评测验证, 采集时只做目录搬迁. 按"参考实现 (已知偏离题目)"看待: 评测脚本查出它的段码表缺 `C`/`P`/`E` 三个字母, 温度与参数界面的标识符与题目不符 (详见下节); 其余功能实测与题目一致.

## 评测脚本

`judge/full.rhai` 按题目原文推导, 共 5 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 上电处于数据界面显示 16:59 之后的时间, 参数默认 17/25/4 | 4.3-1, 4.6 |
| 2 | `S5` 循环切换 时间/温度/亮暗状态 三个数据界面, 格式与读数正确 | 4.2-1, 4.3-1 |
| 3 | 参数界面 `S5` 切换三组参数, `S8`/`S9` 加减并受范围约束 (指示灯参数下限 4) | 4.3-2, 4.4-1 |
| 4 | 低分压 (0.32V) 判为暗状态, 暗持续 3 秒后 `L3` 与指定 `L4` 点亮, 转亮后熄灭 | 4.3-1, 4.5-3/4 |
| 5 | 时间窗口与温度指示: 20:20 在 17 时至次日 08:00 之间时 `L1` 亮, 09:00 时灭; 温度低于参数时 `L2` 亮 | 4.5-1/2 |

运行方式:

```shell
just judge-sample na11
```

当前回归结果: 1 项通过, 4 项失败 (第 1, 2, 3, 4 项, 见下).

## 评测脚本发现的实现问题

| 位置 | 题目要求 | 实测 | 说明 |
| --- | --- | --- | --- |
| 温度数据界面 | 标识符 `C` | 显示 `F` | 该实现的段码表中只有 F, H, S 三个字母项, 没有 `C` |
| 参数界面 | 标识符 `P` + 编号 1/2/3 | 显示 `H4`, `H5`, `H6` | 同上, 标识符与编号都与题目不符 |
| 亮暗状态界面 | 标识符 `E` | 显示 `H` | 同上 |

其余实测结果与题目一致: 时间数据格式与刷新, 温度读数, 亮暗分压与状态位判断, 三组参数的加减与边界, 参数退出后生效, 时间窗口指示 `L1`, 温度指示 `L2`, 暗状态 3 秒后 `L3` 与指定 `L4` 点亮.
