# PA12-2 第十二届蓝桥杯单片机省赛第二场

题目原文见 [problem/12届_第二批_单片机_程序设计.pdf](problem/12届_第二批_单片机_程序设计.pdf), 程序设计部分 70 分.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为 BTN 独立按键模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 通过 P34 引脚测量 NE555 模块输出信号的频率, 需要把 J3 排针的 SIGNAL 与 P34 短接.
- 通过 PCF8591 采集电压, 光敏电阻 RD1 为通道 1, 电位器 Rb2 为通道 3.
- 数码管显示频率, 周期与电压.
- 按键完成界面切换, 通道切换与缓存.
- LED 指示实时值与缓存值的关系以及当前界面.

## 显示格式

| 界面 | 标识位 | 内容 | 示例 |
| --- | --- | --- | --- |
| 频率界面 | `F` | 频率, 单位 Hz, 7 位数码管显示, 高位熄灭 | `F   2035` |
| 周期界面 | `N` | 周期, 单位微秒, 7 位数码管显示, 高位熄灭 | `N    491` |
| 电压界面 | `U` | 通道编号占 2 位 (`-1` / `-3`), 电压保留 2 位小数 | `U-1  3.25` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 界面键, 按 频率界面 -> 周期界面 -> 电压界面 的顺序循环切换 |
| `S5` | 电压通道键, 在电压界面下切换通道 1 与通道 3 |
| `S6` | 通道 3 电压缓存键, 保存当前采集到的电压, 任何界面下均有效 |
| `S7` | 频率缓存键, 保存当前采集到的频率, 任何界面下均有效 |

其它要求:

- 每次从周期界面进入电压界面后, 均显示通道 1 电压.
- 按键做消抖处理, 一次按键只触发一次.
- 按键动作不影响数码管显示与数据采集.
- 长按 `S7` 超过 1 秒后松开, 判定为 `S7` 长按键功能, 关闭 LED 指示灯功能, 所有 LED 熄灭; 再次长按超过 1 秒后松开恢复.

## LED 指示灯

| 指示灯 | 点亮条件 |
| --- | --- |
| `L1` | 通道 3 的实时电压数据大于缓存电压数据 |
| `L2` | 实时频率值大于缓存频率数据 |
| `L3` | 当前处于频率界面 |
| `L4` | 当前处于周期界面 |
| `L5` | 当前处于电压界面 |
| `L6`, `L7`, `L8` | 保持熄灭 |

## 初始状态

- 处于频率显示界面.
- LED 指示灯功能开启.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 数据刷新时间 | <= 1s |
| 频率测量精度 | <= ±8% |
| 电压测量精度 | <= ±5% |
| 按键动作响应时间 | <= 0.2s |

## 满分代码

- `src/driver/`: 数码管, 按键, LED, IIC 与初始化驱动.
- `src/user/main.c`: 频率测量, ADC 采集, 缓存与指示灯逻辑.
- `prj/pa12-2.uvproj`: Keil 工程, 文件路径已改到本仓库的相对布局, 输出名为 `pa12-2`.
- `prj/Objects/pa12-2.hex`: 满分代码的编译产物, 也是评测脚本的输入.

代码取自 4T 可测评场次的满分代码, 只做目录搬迁, 未改动逻辑.

## 评测脚本

`judge/full.rhai` 按题目原文推导, 共 8 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 上电处于频率界面, 显示 `F` 与 2035Hz, `L3` 点亮, 频率精度 ±8% | 4.2-2, 4.3-1, 4.5, 4.6 |
| 2 | 改频后 1s 内刷新显示, 12345Hz 时高位不显示多余的 0 | 4.2-1, 4.3-1 |
| 3 | `S4` 切到周期界面, 1000Hz 对应 1000μs, `L4` 点亮 | 4.3-2, 4.5-4 |
| 4 | 电压界面先显示通道 1 (3.25V), `S5` 切到通道 3 (1.80V), `L5` 点亮, 再次进入回到通道 1 | 4.3-3, 4.4-1, 4.5-5 |
| 5 | `S6` 缓存通道 3 电压后, 实时电压升高点亮 `L1`, 降低熄灭 | 4.4-1, 4.5-1 |
| 6 | `S7` 缓存频率后, 实时频率升高点亮 `L2`, 降低熄灭 | 4.4-1, 4.5-2 |
| 7 | `S4` 三次按键依次经过周期, 电压界面后回到频率界面, 每次均在 200ms 内完成 | 4.2-4, 4.4-1 |
| 8 | 长按 `S7` 超过 1s 松开后全部指示灯熄灭, 再次长按恢复 `L3` | 4.4-2, 4.5 |

运行方式:

```shell
just judge-sample pa12-2
```

当前回归结果: **8 项全部通过**.

## 备注

- 题目中周期界面的标识符是 `N`, 电压界面的标识符是 `U`, 仿真器原来的段码解码表没有这两个字符 (段码 `0x37` 与 `0x3E`), 已补充到默认解码表.
- 频率为窗口测量, 输入频率突变后的第一次测量会跨越新旧两个窗口, 因此评测脚本在改频后等待一个完整测量窗口再断言数值; 数据刷新时间仍按题目要求的 1s 检查.
- 缓存的初值按上电后的第一次采集理解, 评测脚本先用 `S6` / `S7` 建立确定的缓存值, 再改变实时值检查指示灯.
