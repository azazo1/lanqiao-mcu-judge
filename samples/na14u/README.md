# NA14U 第十四届蓝桥杯单片机国赛 (大学组)

题目原文见 [problem/14F_单片机程序设计试题（大学组）.pdf](problem/14F_单片机程序设计试题（大学组）.pdf), 程序设计部分 85 分. 同目录还附了米醋工作室整理的两份辅助文档 (界面流转, 考察重点).

同一届国赛的另一个组别 (职业院校组) 见 [../na14/](../na14/README.md). 两份题目的硬件配置, 显示格式, 参数与工厂模式, DAC 对应关系, LED 与继电器要求完全一致, 本文不再重复, 只列大学组的差异与本 sample 的交付物; 通用部分的说明请看 `na14` 的 README.

## 大学组与职业院校组的差异

| 项目 | 职业院校组 (`na14`) | 大学组 (本 sample) |
| --- | --- | --- |
| 测距重复性 | <= 2cm | <= 1cm |
| `S9` 输出要求 | 按下后开始通过 DAC 输出已记录的数据 | 追加要求: 输出过程中数据采集, 显示和按键功能不受影响 |

其余条目 (测距精度 ±3cm, 范围 10-90cm, 按键响应 <= 0.1s, 温度与超声波刷新 <= 1s, 输出响应 <= 0.1s, 初始状态 40cm/30 摄氏度/0cm/340m/s/1.0V) 两份题目一致.

## 满分代码

- `src/driver/`: 数码管, 按键, LED, IIC, DS18B20, 超声波 (`ultrasound`) 与滤波 (`filtering`) 等驱动.
- `src/user/main.c`: 界面状态机, 参数管理, 校准与传输速度, 记录与 DAC 输出, 继电器与指示灯逻辑.
- `prj/na14u.uvproj`: Keil 工程, 输出名为 `na14u` (原工程名为 `demo`).
- `prj/Objects/na14u.hex`: 编译产物, 也是评测脚本的输入.

代码来自米醋工作室的第十四届国赛工程, 采集时只改了工程输出名, 其余未改动.

## 评测脚本

`judge/full.rhai` 共 8 个评测点, 与 `na14` 的结构对应, 并按大学组的两处差异做了加强:

| 序号 | 评测点 | 与 `na14` 的差别 |
| --- | --- | --- |
| 1 | 上电处于测距界面 (cm), 五组默认参数 40/30/0/340/1.0, 测距精度 ±3cm | 相同 |
| 2 | `S5` 切换 cm/m 并重新进入恢复 cm; 追加同一距离连续三次测量差值不超过 1cm | 重复性按大学组的 1cm 判定 |
| 3 | `L1`-`L8` 表示距离二进制, 参数界面只亮 `L8`, 工厂模式 `L1` 以 0.1s 闪烁 | 相同 |
| 4 | 参数与工厂模式各界面的步进加减 (10cm/1 摄氏度/5cm/10m/s/0.1V) | 相同 |
| 5 | 校准值生效: 校准 10cm 后测距结果增加约 10cm | 相同 |
| 6 | 继电器在 距离参数 ±5cm 且温度不超过温度参数 时吸合 | 相同 |
| 7 | `S8` 记录 6 秒距离变化后 `S9` 输出: 记录期间显示正常, 输出值随记录变化且落在下限值与 5.0V 之间, 输出过程中显示与采集不受影响 | 追加输出过程不影响采集与显示 |
| 8 | 响应时间: 按键 <= 0.1s, 超声波刷新 <= 1s, 输出动作 <= 0.1s (实测 0ms / 450ms / 0ms) | 3.2 |

运行方式:

```shell
just judge-sample na14u
```

当前回归结果: **8 项全部通过**. 与职业院校组那份社区实现相比, 这份米醋实现把记录与 DAC 输出完整实现了 (实测输出序列 `1686, 1941, 2196, 2431, 2686 mV` 随记录的距离变化).

## 备注

- 采样实现的超声波需要若干采集周期才给出有效读数: 上电后 1.2s 读到的距离仍是 0, 评测脚本把采集等待量设为 2s (题目允许的刷新时间是 <= 1s).
- 工厂模式的 `L1` 闪烁需要采样观察, 单次读取可能落在熄灭相位.
