# PA15 第十五届蓝桥杯单片机省赛 (大学组)

题目原文见 [problem/15届省赛.pdf](problem/15届省赛.pdf), 程序设计部分 85 分.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为矩阵键盘 (KBD) 模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 通过 P34 引脚测量 NE555 输出的脉冲信号频率.
- 频率数据校准: 系统内置校准值参数, 直接测量值加校准值作为最终频率数据.
- 频率超限报警: 当前频率数据大于超限参数时闪烁报警指示灯.
- 通过 DS1302 获取时间数据.
- 数码管显示频率, 参数, 时间与回显数据.
- 按键完成界面切换与参数设定.
- 通过 PCF8591 输出与频率数据对应的模拟电压.

## 显示格式

| 界面 | 提示符 | 内容 | 示例 |
| --- | --- | --- | --- |
| 频率界面 | `F` | 5 位数码管显示频率, 单位 Hz, 高位熄灭 | `F   2350` |
| 超限参数界面 | `P1` | 超限参数, 单位 Hz | `P1  2000` |
| 校准值参数界面 | `P2` | 校准值, 单位 Hz, 负数显示符号 | `P2  -300` |
| 时间界面 | 无 | 时, 分, 秒各占 2 位数码管, 用 `-` 分隔, 不足 2 位补 0 | `13-03-05` |
| 频率回显界面 | `HF` | 最大频率值, 5 位数码管, 高位熄灭 | `HF  8242` |
| 时间回显界面 | `HA` | 最大频率发生的时间, 6 位数码管 | `HA123554` |
| 错误状态 | `F` | 校准后频率为负时固定显示 `LL` | `F     LL` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 界面键, 按 频率界面 -> 参数界面 -> 时间界面 -> 回显界面 的顺序循环切换 |
| `S5` | 选择键, 参数界面下切换超限参数与校准值, 回显界面下切换频率回显与时间回显 |
| `S8` | 加键, 超限参数加 1000Hz, 校准值加 100Hz |
| `S9` | 减键, 超限参数减 1000Hz, 校准值减 100Hz |

其它要求:

- 按键做消抖处理, 一次按键只触发一次.
- 按键动作不影响数据采集与数码管显示.
- 每次从频率界面切换到参数界面时处于超限参数子界面.
- 每次从时间界面切换到回显界面时处于频率回显子界面.
- 参数调整时考虑边界值: 超限参数范围 1000Hz 到 9000Hz, 校准值范围 -900Hz 到 900Hz, 到达边界后不再变化.

## 频率处理与 DAC

- 最终频率数据 = 直接测量到的频率 + 校准值参数.
- 若校准后频率为负数, 频率界面显示 `LL`, 报警指示灯常亮, DAC 固定输出 0V.
- DAC 输出与频率数据的关系见图 7: 低频端对应 1.0V 输出, 频率达到超限参数时输出 5.0V, 之后保持 5.0V.
- 频率最大值统计: 记录最大频率值与发生时间, 可在回显界面查看.

## LED 指示灯

| 指示灯 | 行为 |
| --- | --- |
| `L1` | 频率界面下以 0.2 秒为间隔切换亮灭, 其余界面熄灭 |
| `L2` | 频率数据大于超限参数时以 0.2 秒为间隔切换亮灭, 否则熄灭; 频率状态错误时常亮 |
| 其余指示灯 | 保持熄灭 |

## 初始状态

- 处于频率界面.
- 频率超限参数 2000Hz.
- 频率校准值 0.

## 评测脚本的修正记录

第 6 项 (回显界面) 曾经判为失败, 后来查明是评测脚本自身的问题, 实现没有错:

- 频率回显的比对取错了界面. 断言里用 `display_number(3, 8)` 读"当前"显示时, 界面已经切到时间回显, 于是把时间回显的 6 位时间当成了频率回显值 (实测 `HF233916`, `HF130306` 这类数字其实来自时间回显). 改成在读取频率回显文本的同时立刻取数值后, 实测 `HF  2036` 与频率界面的 `F   2035` 一致 (题目允许的频率测量误差 ±8%, 窗口 ±163).
- 指示灯断言过严. 该场景输入频率 2035Hz 高于超限参数, 报警指示灯 `L2` 本就应该闪烁, 而脚本原来要求回显界面下 8 个指示灯全灭. 现在改为断言非频率界面下 `L1` 熄灭, 其余除 `L2` 外全部熄灭.
- 时间回显的时, 分改按合法值断言 (0-23, 0-59). 回显的是"最大频率出现的时刻", 频率恒定且从开机就有效时该时刻落在开机那一刻 (实测 `HA235951`), 不会等于脚本后来通过 `set_rtc` 设置的 13 时, 因此不能按相等断言.

## 备注

- 图 7 的直线从横轴起点 (标为 0) 的 1.0V 上升到超限参数处的 5.0V, 之后保持 5.0V. 采样实现在 500Hz 以下保持 1.0V, 之后按 (500Hz, 1.0V) 到 (超限参数, 5.0V) 线性上升, 与图 7 只在两个端点重合, 中间段偏低 (超限参数 2000Hz 时, 测量 1000Hz 的实测输出为 2333mV, 图 7 的直线对应 3000mV). 评测脚本按端点与单调性判定, 中间点只要求落在 1.0V 到 5.0V 之间, 避免把图 7 的横轴起点读数歧义固化进评测.
- 时间回显界面的提示符在图 6-2 中画作 `HA`, 正文写作 `HR`, 两者不一致; 评测脚本接受 `HA` 与 `HR` 两种写法.
- 参数在边界处的处理实测为夹紧 (到达 9000Hz 或 -900Hz 后继续按键数值不再变化).
- 采样实现的按键释放间隔要求较长, 连续切换界面时若两次按键只间隔 0.1s, 第二次会被丢弃. 评测脚本中导航用的按键间隔取 0.25s, 按键响应时间用单独评测点按题目要求的 0.1s 判定.
- 采样实现的 DS1302 在启动阶段会写入初始时间, 评测脚本在启动初始化完成之后再设置 RTC.
