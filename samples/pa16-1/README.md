# PA16-1 第十六届蓝桥杯单片机省赛 (大学组)

题目原文见 [problem/16届省赛（扫描件）.pdf](problem/16届省赛（扫描件）.pdf), 程序设计部分 85 分.
该 PDF 是扫描件没有文本层, 已用本地 Apple Vision OCR 转成 [problem/题目OCR文本.txt](problem/题目OCR文本.txt), 本样例的题目整理与评测点推导均以该 OCR 文本为准 (图 3 到图 7 的数码管版式在扫描件里只有图形, OCR 只能给出图注).

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为矩阵键盘 (KBD) 模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 通过 DS18B20 检测环境温度.
- 通过光敏电阻 (接 AD 芯片) 检测环境亮暗程度.
- 通过超声波模块检测物体的接近与运动状态 (静止, 徘徊, 跑动).
- 数码管显示, 键盘切换界面与设置参数, LED 指示灯与继电器输出.

## 光强等级与移动检测

| 光强等级 | 分压结果 VAIN |
| --- | --- |
| `N1` | >= 3.0V |
| `N2` | 2.0V <= VAIN < 3.0V |
| `N3` | 0.5V <= VAIN < 2.0V |
| `N4` | < 0.5V |

- 距离值低于距离参数 `PL` 时触发接近判定.
- 设备间隔 1 秒采集距离, 连续两次采集的距离差值 `ΔL` 决定运动状态: `ΔL < 5cm` 为静止 (L1), `5cm <= ΔL < 10cm` 为徘徊 (L2), `ΔL >= 10cm` 为跑动 (L3).
- 运动状态变化时立即更新并锁定 3 秒, 锁定期间保持距离采集但不判定状态变化.

## 输出控制

| 输出 | 行为 |
| --- | --- |
| `L1`-`L4` | 触发接近判定时按光强等级点亮: N1 只亮 L1, N2 亮 L1-L2, N3 亮 L1-L3, N4 亮 L1-L4; 未触发接近时全部熄灭 |
| `L8` | 运动状态指示: 静止熄灭, 徘徊点亮, 跑动以 0.1 秒为间隔闪烁 |
| 继电器 | 同时触发接近与高温判定时吸合, 否则断开 |
| 其余指示灯与蜂鸣器 | 保持熄灭与静音 |

## 显示格式

| 界面 | 内容 | 示例 |
| --- | --- | --- |
| 环境状态界面 | 温度整数与光强等级 | `C23   N4` |
| 运动检测界面 | 运动状态编码与 3 位距离 (不足补 0) | `L1   035` |
| 温度参数界面 | 参数编号与温度参数 | `PC    30` |
| 距离参数界面 | 参数编号与距离参数 | `PL    30` |
| 统计数据界面 | 统计编号与继电器吸合次数 (4 位, 高位熄灭) | `NC     1` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 循环切换 环境 -> 运动 -> 参数 -> 统计 四个界面, 任意界面下有效; 进入参数界面时 LED 与继电器状态锁定, 退出后解除 |
| `S5` | 参数界面下切换温度参数与距离参数两个子界面; 每次从运动检测界面进入参数界面默认温度参数 |
| `S8` | 温度参数加 1 摄氏度, 距离参数加 5cm |
| `S9` | 温度参数减 1 摄氏度, 距离参数减 5cm |
| `S8` + `S9` | 统计界面下同时按下保持 2 秒以上清零继电器吸合次数 |

参数范围: 温度参数 20-80 摄氏度, 距离参数 20-80cm.

## 初始状态

- 处于环境状态界面.
- 温度参数 30 摄氏度, 距离参数 30cm.
- 未涉及指示灯熄灭, 蜂鸣器静音.

## 评测脚本发现的实现问题

当前回归结果: 6 项通过 (第 3, 4, 5, 6, 7, 8 项), 2 项失败 (第 1, 2 项, 均为光强等级同一根因).

- 光强等级只产生 N1/N2/N4 三级, 题目要求的 N3 (0.5V 到 2.0V) 从未出现 (第 1, 2 项). 两个方向的扫描结果:
  - 电压上升 (每个电压保持 4 秒): 0.2V/0.6V/1.0V/1.5V 都是 N4, 2.0V/2.5V 是 N2, 3.0V/3.5V 是 N1.
  - 电压下降: 3.5V 是 N1, 2.5V 是 N2, 2.0V 及以下都是 N4.
  也就是说 2.0V 在上升与下降时判定不同 (实现里存在迟滞), 而 0.5V 到 2.0V 这一段始终没有判成 N3. 灯光控制连带出错: 接近判定下 1.0V 时点亮 L1-L4, 而题目要求 N3 只点亮 L1-L3.
- 运动状态判定的观察窗口已复核 (第 3, 4 项): 题目要求每 1 秒采集一次且状态变化后锁定 3 秒, 把观察窗口放宽到 3.5 秒后, 静止 (距离不变), 徘徊 (变化 7cm), 跑动 (变化 20cm) 三种状态都能正确判定, 之前的失败是评测脚本窗口偏短.
- 上电初期会先停留在跑动状态, 进入运动检测界面约 3 秒后回到静止. 评测脚本在每个检查点先等待状态锁定结束再断言.

其余实测与题目一致: 温度显示与光强等级字符, 运动检测界面距离补 0 显示, `L8` 对静止与徘徊的指示, 继电器在接近且高温时吸合与吸合次数统计及清零, 参数加减与范围, 其余指示灯熄灭与蜂鸣器静音.

## 备注

- 采样实现需要若干个采集周期后输出与状态才稳定 (上电后约 4 秒), 评测脚本在每个检查点开始时统一等待 4 秒再断言, 避免把上电初期的未稳定状态当成结果.
- 运动状态的 3 秒锁定会影响连续判定, 评测脚本在相邻两次状态变更之间留出锁定时间.
