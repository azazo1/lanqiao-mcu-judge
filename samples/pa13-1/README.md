# PA13-1 第十三届蓝桥杯单片机省赛第一场 (大学组)

题目原文见 [problem/13P_P1_单片机程序设计（大学组）.pdf](problem/13P_P1_单片机程序设计（大学组）.pdf), 程序设计部分 85 分.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为 KBD 键盘模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 通过 DS18B20 获取环境温度.
- 通过 DS1302 获取时, 分, 秒.
- 数码管显示温度, 时间与温度参数.
- 按键完成界面切换, 模式切换与参数调整.
- 继电器按温度或时间条件动作, LED 指示灯给出状态指示.
- 蜂鸣器与试题功能无关, 运行过程保持静音.

## 显示格式

| 界面 | 界面编号 | 内容 | 示例 |
| --- | --- | --- | --- |
| 温度界面 | `U1` | 温度, 保留 1 位小数, 单位摄氏度 | `U1   23.5` |
| 时间界面 | `U2` | 时-分, 24 小时制, `-` 为分隔符 | `U2 23-25` |
| 时间界面 (按住 `S17`) | `U2` | 分-秒, `-` 为分隔符 | `U2 53-20` |
| 参数界面 | `U3` | 温度参数, 整数, 单位摄氏度 | `U3    23` |

界面编号占最左侧两位, 之后是若干熄灭位, 数值右对齐.

## 按键

| 按键 | 功能 |
| --- | --- |
| `S12` | 切换键, 按 温度界面 -> 时间界面 -> 参数界面 的顺序循环切换 |
| `S13` | 模式键, 在温度控制模式与时间控制模式之间切换 |
| `S16` | 加键, 参数界面下温度参数加 1 摄氏度 |
| `S17` | 减键, 参数界面下温度参数减 1 摄氏度; 时间界面下按住时显示分, 秒 |

其它要求:

- 按键做消抖处理, 一次按键只触发一次.
- 按键动作不影响数码管显示与数据采集.
- `S16` 只在参数界面有效; `S17` 在时间界面与参数界面有效.
- 温度参数调整范围 10 摄氏度到 99 摄氏度.

## 继电器与指示灯

| 对象 | 行为 |
| --- | --- |
| 继电器 (温度控制模式) | 采集温度超过温度参数时吸合, 否则断开 |
| 继电器 (时间控制模式) | 每个整点吸合, 5 秒后断开 |
| `L1` | 整点时开始点亮, 5 秒后熄灭 |
| `L2` | 工作模式指示灯, 温度控制模式点亮, 时间控制模式熄灭 |
| `L3` | 继电器吸合时以 0.1 秒为间隔切换亮灭, 否则熄灭 |
| 其余指示灯 | 保持熄灭 |

两种工作模式互不影响.

## 初始状态

- 处于温度显示界面.
- 工作模式为温度控制.
- 温度参数为 23 摄氏度.
- 蜂鸣器静音.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 温度数据采集刷新时间 | <= 1s |
| 按键动作响应时间 | <= 0.2s |
| 继电器响应时间 | <= 0.1s (条件触发后) |

## 满分代码

- `src/driver/`: 数码管, 按键, LED, DS18B20, DS1302 与初始化驱动.
- `src/user/main.c`: 界面状态机, 参数管理, 继电器控制与指示灯逻辑.
- `prj/pa13-1.uvproj`: Keil 工程, 文件路径已改到本仓库的相对布局, 输出名为 `pa13-1`.
- `prj/Objects/pa13-1.hex`: 满分代码的编译产物, 也是评测脚本的输入.

代码取自 4T 可测评场次的满分代码, 只做目录搬迁, 未改动逻辑.

## 备注

- 采样实现的 DS1302 在启动阶段会写入初始时间, 评测脚本在启动初始化完成之后再设置 RTC, 并把时间设到非整点, 避免整点事件干扰其它评测点.
- 整点动作按 10ms 分辨率核对过: 采样实现从整点到继电器吸合的延迟在 10ms 到 160ms 之间波动, 本次回归为 110ms, 保持时间稳定为 5000ms. 脚本无法直接读 DS1302 的内部秒边界, 所以吸合延迟的断言窗口取题目的 0.1s 加一个采样周期的相位余量, 写成 0.2s; 保持时间仍按 5s 严格核对 (吸合后 4.9s 仍吸合, 5.1s 已断开).
- 温度类断言的等待量取温度刷新 1s 加继电器响应 0.1s 再加少量采样余量.
