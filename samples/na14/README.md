# NA14 第十四届蓝桥杯单片机国赛 (职业院校组)

题目原文见 [problem/14F_单片机程序设计试题（职业院校组）.pdf](problem/14F_单片机程序设计试题（职业院校组）.pdf), 程序设计部分 85 分.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为矩阵键盘 (KBD) 模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 超声波测距, 传输速度与校准值可在工厂模式调整.
- DS18B20 温度测量.
- PCF8591 输出已记录的距离变化.
- 继电器与 LED 指示灯输出控制与状态指示.
- 数码管与按键完成显示, 界面切换与参数设置.

## 显示格式

| 界面 | 标识 | 内容 | 示例 |
| --- | --- | --- | --- |
| 测距界面 (cm) | 无 | 温度 (1 位小数) + `-` + 距离整数 (4 位, 高位熄灭) | `23.5-  25` |
| 测距界面 (m) | 无 | 距离以 m 显示, 保留 2 位小数 | `23.5- 0.25` |
| 距离参数 | `P1` | 距离参数, 范围 10-90cm | `P1    40` |
| 温度参数 | `P2` | 温度参数, 范围 0-80 摄氏度 | `P2    30` |
| 校准值设置 | `F1` | 校准值, 3 位数码管, 可正可负 | `F1     5` / `F1    -5` |
| 介质设置 | `F2` | 传输速度, 单位 m/s, 范围 10-9990 | `F2   340` |
| DAC 输出设置 | `F3` | DAC 输出下限值, 1 位小数, 范围 0.1-2.0V | `F3    1.0` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 在 测距界面 -> 参数界面 -> 工厂模式 之间循环切换 |
| `S5` | 测距界面切换 cm/m (重新进入默认 cm); 参数界面切换 P1/P2 (默认 P1); 工厂模式切换 F1/F2/F3 (默认 F1) |
| `S8` | 各界面的加键 (距离 +10cm, 温度 +1 摄氏度, 校准值 +5cm, 传输速度 +10m/s, DAC 下限 +0.1V); 测距界面下为记录键, 记录接下来 6 秒的距离变化 |
| `S9` | 各界面的减键 (步进同 `S8`); 测距界面下为输出键, 通过 DAC 输出已记录的数据 |
| `S8` + `S9` | 同时按下超过 2 秒恢复出厂设置 |

记录过程中所有按键无效; 只保留最近一次记录的数据; 参数只在各自界面生效.

## DAC, 测距与输出

- 测距结果 = 传输速度 × 传输时间 / 2 + 校准值.
- DAC 输出与已记录的距离数据成直线: 10cm 对应输出下限值 VOL, 90cm 对应 5.0V, 参考电压 5.0V.

## LED 与继电器

| 输出 | 行为 |
| --- | --- |
| `L1`-`L8` (测距界面) | 表示距离值的 8 位二进制 (L1 为最低位), 距离不小于 255cm 时全亮 |
| `L8` (参数界面) | 参数界面下只点亮 L8 |
| `L1` (工厂模式) | 以 0.1 秒为间隔闪烁, 其余指示灯熄灭 |
| 继电器 | 距离参数-5cm <= 测距结果 <= 距离参数+5cm 且 温度 <= 温度参数 时吸合, 否则断开 |

## 初始状态

- 处于测距界面, 显示单位为 cm.
- 距离参数 40cm, 温度参数 30 摄氏度, 校准值 0cm, 传输速度 340m/s, DAC 输出下限值 1.0V.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 测距精度 | ±3cm |
| 测距重复性 | <= 2cm |
| 测距范围 | 10cm - 90cm |
| 按键响应时间 | <= 0.1s |
| 温度与超声波刷新时间 | <= 1s |
| 输出动作响应时间 | <= 0.1s |

- `src/driver/`: 数码管, 按键, LED, IIC, DAC, DS18B20, 超声波与初始化驱动.
- `src/user/main.c`: 界面状态机, 参数管理, 校准与传输速度, 记录与 DAC 输出, 继电器与指示灯逻辑.
- `prj/na14.uvproj`: Keil 工程, 文件路径已改到本仓库的相对布局, 输出名为 `na14`.
- `prj/Objects/na14.hex`: 编译产物, 也是评测脚本的输入.

## 评测脚本发现的实现问题

- 记录与 DAC 输出功能没有实现. 按题目 3.4 与 3.5, 在测距界面按 `S8` 应记录接下来 6 秒的距离变化, 记录完成后按 `S9` 应通过 DAC 输出这段记录 (10cm 对应输出下限值, 90cm 对应 5.0V). 实测: 固定距离与 6 秒内连续变化距离两种情形下, 记录完成并按 `S9` 之后 DAC 输出始终为 0 (逐 300ms 采样 3 秒均为 0), 即该实现没有驱动 DAC 输出记录数据. 其余功能 (测距与单位切换, 温度显示, 参数与工厂模式加减, 校准值生效, 指示灯二进制显示, 继电器控制) 均与题目一致.
