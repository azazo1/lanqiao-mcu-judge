# PA17 第十七届蓝桥杯单片机省赛 (大学组)

题目原文见 [problem/SCMA_17PD.pdf](problem/SCMA_17PD.pdf) (有文本层, 直接读取); 同目录另有客观试题 `SCM_17PS.pdf` 与米醋工作室的考点讲解.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式 J5 配置为矩阵键盘 (KBD) 模式.
- 扩展方式 J13 配置为 IO 模式.

## 功能

设计一款智能压力变送器: 由 PCF8591 采集电位器电压并线性换算为压力值, 支持数据标定, 地址设置, 参数存储, 工厂模式与串口通信.

- 双点标定: 零点校准值 PL 与满量程校准值 PH 在工厂模式可调, 单位为 kPa, 保留 1 位小数.
- 泄压记录: 当前压力比 3 秒前低 1.5kPa 以上时触发泄压事件并记录时间, 持续下降或上升过程中不重复记录.
- 时间由 DS1302 提供, 参数存放在 EEPROM.

## 显示格式

| 界面 | 内容 | 示例 |
| --- | --- | --- |
| 运行界面 | 时 (2 位) 分 (2 位) + 压力值 (1 位小数, kPa) | `2203  4.8` |
| 地址设置界面 | 标识 `ae` + 设备地址 (3 位, 高位熄灭) | `AE     8` |
| 泄压记录界面 | 标识 `cc` + 最近一次泄压时间, 未发生时显示 `-` | `CC  1252` / `CC     -` |
| 工厂模式 (满量程) | 标识 `PH` + 满量程校准值 (1 位小数) | `PH   -9.0` |
| 工厂模式 (零点) | 标识 `PL` + 零点校准值 (1 位小数) | `PL   -0.5` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 往复切换 运行界面 / 地址设置界面 / 泄压记录界面 |
| `S5` 长按 3 秒 | 进入或退出工厂模式 (进入时默认为满量程校准值设置, 退出后回到进入前的界面) |
| `S5` 短按 | 工厂模式下切换 满量程校准值 / 零点校准值; 未进入工厂模式时无效 |
| `S8` | 地址设置界面下地址减 1; 工厂模式下当前校准值减 0.1 |
| `S9` | 地址设置界面下地址加 1; 工厂模式下当前校准值加 0.1 |
| `S12` | 地址设置界面下保存地址到 EEPROM; 工厂模式下保存当前校准值 (未保存的参数只在本次运行生效) |
| `S13` 短按 | 泄压记录界面下清除泄压事件记录 |
| `S13` 长按 3 秒 | 任一界面下恢复出厂值 (满量程 9.0kPa, 零点 0.0kPa, 地址 8) 并写入 EEPROM, 显示跳转到运行界面 |

参数范围: 满量程与零点校准值 0.0-9.9kPa, 设备地址 1-100.

## EEPROM 与串口

| 内容 | 地址 | 存储方式 |
| --- | --- | --- |
| 特征字 | `0x00` | 不等于 `0xAA` 时视为首次上电, 写入出厂值 9.0kPa / 0.0kPa / 地址 8, 并写入 `0xAA` |
| 零点校准值 | `0x01` | 实际值的 10 倍, 例如 2.0kPa 存 20 |
| 满量程校准值 | `0x02` | 实际值的 10 倍 |
| 设备地址 | `0x03` | 地址原值 |

- 串口 1: 9600, 8, N, 1, 纯文本, 无附加结束符.
- 查询命令 `#设备地址?` (例如 `#008?`), 返回 `压力数值@时间(时:分)` (例如 `7.2kPa@23:05`).
- 地址不匹配或命令格式错误时保持静默.

## LED 指示灯

| 指示灯 | 行为 |
| --- | --- |
| `L1` | 收到本机压力查询命令后以 0.2 秒为间隔闪烁, 持续 3 秒后熄灭, 期间再收到命令则重置计时 |
| `L2` | 工厂模式下以 0.2 秒为间隔闪烁, 退出后熄灭 |
| `L3` | 泄压事件后常亮, 直到清除泄压记录 |
| 其余 | 保持熄灭 |

## 初始状态

- 运行界面, 串口参数 9600, 8, N, 1, 其余 LED 熄灭.

- `src/user/main.c`: 界面状态机, 压力换算与标定, 泄压判定与记录, EEPROM 存取, 串口查询应答与指示灯逻辑.
- `prj/pa17.uvproj`: Keil 工程, 输出名为 `pa17` (原工程名为考号).
- `prj/Objects/pa17.hex`: 编译产物, 也是评测脚本的输入.

## 评测脚本

`judge/full.rhai` 按题目原文推导, 共 9 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 首次上电 (特征字不等于 `0xAA`) 写入出厂值 9.0/0.0/8 与 `0xAA`, 运行界面显示时间与压力 | 3.4-1, 3.6-3, 四 |
| 2 | 特征字已是 `0xAA` 时, 上电应按 EEPROM 中的校准值与设备地址工作 | 3.6 |
| 3 | 压力线性换算五点: 0V 到 5V 对应 0.0kPa 到满量程 9.0kPa | 3.3-1 |
| 4 | `S4` 循环三个界面, 地址加减与 `S12` 保存到 `0x03` | 3.4-2/3, 3.5, 3.6-2 |
| 5 | 长按 `S5` 进出工厂模式, 短按切换 `PH`/`PL`, 加减 0.1 与 `S12` 保存, 退出后生效 | 3.3-1, 3.4-4, 3.5, 3.6-1 |
| 6 | 串口 `#008?` 返回 `压力@时分`, 地址不匹配时静默, 收到查询时 `L1` 闪烁 | 3.7, 3.8-1 |
| 7 | 压力骤降触发泄压记录时间并点亮 `L3`, `S13` 短按清除记录 | 3.3-2, 3.4-3, 3.5, 3.8-3 |
| 8 | 长按 `S13` 恢复出厂值并写入 EEPROM 且跳转运行界面, 工厂模式下 `L2` 闪烁 | 3.5, 3.8-2 |
| 9 | 响应时间: 模拟信号采样 <= 0.2s, 按键响应 <= 0.1s, 指示灯响应 <= 0.1s | 3.2 |

运行方式:

```shell
just judge-sample pa17
```

当前回归结果: 5 项通过, 4 项失败 (第 2, 6, 8, 9 项, 见下). 第 9 项里模拟信号采样与按键响应都满足题目要求, 只有指示灯响应一项超时.

## 评测脚本发现的实现问题

- 上电不读取 EEPROM 中的校准值与设备地址 (第 2 项). 实测: 预先在 EEPROM 中写入特征字 `0xAA`, 零点校准值 12 (1.2kPa), 满量程校准值 34 (3.4kPa), 设备地址 56; 复位后地址设置界面显示 `AE   255`, 工厂模式显示 `PH   -5.5`, 压力换算也不使用这两组校准值. 而特征字不是 `0xAA` 时, 实现自己写入的出厂值路径正常 (检查点 1 通过), 说明缺的是"从 EEPROM 读回参数"这一步.
- 串口应答中的时间与数码管不一致 (第 6 项). 实测在设置时间 (23:05) 之后查询: 数码管运行界面显示 `2305  4.5` 正确, 而两次串口应答都返回 `4.5kPa@00:00` (间隔 2 秒复测仍为 `00:00`); 压力值部分正确. 另有一次更早的探针在设置时间后等待约 5 秒再查询, 应答是 `9.0kPa@22:03` (与当时设置的 22:03 一致), 说明应答路径取时间存在滞后或时序问题, 具体节奏待进一步定位.
- 工厂模式指示灯 `L2` 不闪烁 (第 8 项). 实测长按 `S5` 已进入工厂模式 (数码管显示 `PH   -9.0`), 随后以 100ms 间隔连续观察 6 秒, `L2` 的输出序列为 60 个 `0`, 即全程熄灭, 与题目 3.8-2 要求的 0.2 秒间隔闪烁不符 (这一次用的是足够长的观察窗, 可以排除采样时机问题).
- 通信指示灯响应时间超过题目上限 (第 9 项). 发出本机查询命令 `#008?` 后, 通信指示灯 `L1` 用了 220ms 才点亮, 超过题目 3.2 的 0.1 秒上限. 需要注意的是, `L1` 按题目 3.8-1 是以 0.2 秒为间隔闪烁, 因此"点亮时刻"最多可能落在一个闪烁周期之后 (0 到 200ms), 实测 220ms 与这个周期量级一致; 这一项先按题目上限断言并记为偏离, 但判定时应当把这个闪烁周期的因素一并考虑.

## 备注

- 采样实现上电会在启动早期读取 EEPROM, 因此评测脚本在复位之前就把 EEPROM 参数写好; 仿真器的 EEPROM 内容可以跨复位保留 (已实测).
- 运行界面的数字串前 4 位是时间, 评测脚本取第 5 位之后的数字作为压力值.
- 压力换算与校准值比较使用放大 10 倍后的整数, 避免脚本里浮点区间比较.
