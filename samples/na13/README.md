# NA13 第十三届蓝桥杯单片机国赛 (大学组)

题目原文见 [problem/13F_单片机程序设计试题（大学组）.pdf](problem/13F_单片机程序设计试题（大学组）.pdf), 程序设计部分 85 分.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为 BTN 独立按键模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 通过超声波传感器测距, 声速按 340m/s (25 摄氏度) 计算.
- 通过 PCF8591 的 ADC 测量电位器 RB2 输出电压, 并换算成湿度.
- 通过 PCF8591 的 DAC 输出电压.
- 通过 P34 采集脉冲信号频率.
- 通过电机驱动引脚输出 1KHz 脉冲, 占空比随频率数据与频率参数的关系切换.
- 使用 E2PROM 记录继电器开关次数.
- 数码管显示, 界面切换, 参数设置与 LED 指示.

## 显示格式

| 界面 | 提示符 | 内容 | 示例 |
| --- | --- | --- | --- |
| 频率界面 (Hz) | `F` | 6 位数码管显示频率, 高位熄灭 | `F    245` |
| 频率界面 (KHz) | `F` | 频率以 KHz 显示, 保留 1 位小数 | `F   24.5` |
| 湿度界面 | `H` | 2 位数码管显示湿度整数, 单位 %RH | `H     35` |
| 测距界面 (CM) | `A` | 3 位数码管显示距离, 高位熄灭 | `A     45` |
| 测距界面 (M) | `A` | 距离以米显示, 保留 2 位小数 | `A    0.45` |
| 频率参数界面 | `P1` | 频率参数, 单位 KHz, 1 位小数, 范围 1.0-12.0 | `P1    1.5` |
| 湿度参数界面 | `P2` | 湿度参数, 范围 10-60 | `P2    20` |
| 距离参数界面 | `P3` | 距离参数, 单位 M, 1 位小数, 范围 0.1-1.2 | `P3    0.5` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 界面键, 按 频率界面 -> 湿度界面 -> 测距界面 -> 参数界面 的顺序循环切换 |
| `S5` | 参数界面下切换频率参数, 湿度参数与距离参数 |
| `S6` | 当前参数加一个步进 (频率 0.5KHz, 湿度 10, 距离 0.1M); 测距界面下切换 CM 与 M 显示 |
| `S7` | 当前参数减一个步进; 频率界面下切换 Hz 与 KHz 显示; 湿度界面下长按超过 1s 松开清零继电器开关次数 |

其它要求:

- 按键做消抖处理, 一次按键只触发一次; 长按键与短按键功能不重复触发.
- 按键动作不影响数码管显示与数据采集.
- 每次从测距界面切换到参数界面, 默认当前为频率参数.
- 参数加到最大值后继续加回绕到最小值, 减到最小值后继续减回绕到最大值.

## 测量与输出

- 湿度: 电位器 RB2 电压 (0V-5V) 线性对应湿度 0-100%RH.
- DAC: 输出电压与湿度数据成直线关系, 直线经过 (湿度参数, 1.0V) 与 (80%RH, 5.0V).
- 继电器: 测距结果大于距离参数时吸合, 否则断开.
- 脉冲输出: 频率数据大于频率参数时电机驱动引脚输出 1KHz 80% 占空比, 否则输出 1KHz 20% 占空比.
- E2PROM: 继电器开关次数保存在地址 0.

## LED 指示灯

| 指示灯 | 行为 |
| --- | --- |
| `L1` | 频率界面下点亮, 频率参数界面下以 0.1s 闪烁, 其余界面熄灭 |
| `L2` | 湿度界面下点亮, 湿度参数界面下以 0.1s 闪烁, 其余界面熄灭 |
| `L3` | 测距界面下点亮, 距离参数界面下以 0.1s 闪烁, 其余界面熄灭 |
| `L4` | 频率数据大于频率参数时点亮 |
| `L5` | 湿度数据大于湿度参数时点亮 |
| `L6` | 距离数据大于距离参数时点亮 |
| `L7`, `L8` | 保持熄灭 |

## 初始状态

- 处于频率界面, 单位为 Hz.
- 距离界面单位为 CM.
- 频率参数 9.0KHz, 湿度参数 40%, 距离参数 0.6M.

## 备注

- 采样实现的测距读数比设定距离大 1cm (例如设定 45cm 显示 46), 在题目的 ±3cm 之内.
- 湿度显示按直线换算后取整, 实测 1.75V 显示 34 (理论 35), 4.60V 显示 92 (理论 92), 评测脚本按 ±2 判定.
- 图 15 的横轴左端是湿度参数, 因此直线随参数移动; 评测脚本据此把"参数改变后同湿度数据对应不同输出电压"也纳入检查.
- 电机驱动引脚在仿真器中通过继电器驱动锁存位观察: 评测脚本按 25μs 步长采样 2ms, 用导通比例判断占空比, 用跳变次数判断确实在输出脉冲.
- E2PROM 计数实测按继电器每次状态变化累加 (吸合与断开各计 1 次), 评测脚本据此检查; 计数清零在湿度界面长按 `S7` 超过 1s 后松开生效.
