# PA11-1 第十一届蓝桥杯单片机省赛 (第一次)

题目原文是扫描件: [problem/11 第十一届省赛（第一次）题目_程序题.pdf](problem/11%20第十一届省赛（第一次）题目_程序题.pdf), 已用本地 Apple Vision OCR 转成 [problem/题目OCR文本.txt](problem/题目OCR文本.txt); 同目录另有米醋工作室的界面流转与考察重点两份文档.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为 KBD 矩阵键盘模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 用 PCF8591 的 AIN3 通道测量电位器 Rb2 输出的电压 VAIN3.
- 数码管显示数据, 计数与参数三个界面, 按键切换.
- AT24C02 保存电压参数, 占用内部地址 0 一个字节.
- LED 指示灯做超时与状态提醒.

## 显示格式

| 界面 | 内容 | 示例 |
| --- | --- | --- |
| 数据界面 | 提示符 `U` + 电压值, 保留 2 位小数 | `U    3.24` |
| 参数界面 | 提示符 `P` + 电压参数, 保留 2 位小数 | `P    3.00` |
| 计数界面 | 提示符 `N` + 计数值 | `N      12` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S12` | 依次切换 数据界面 -> 参数界面 -> 计数界面 |
| `S13` | 计数界面下把当前计数值清零 |
| `S16` | 参数界面下电压参数加 0.5V, 加到 5.00V 后再按返回 0.00V |
| `S17` | 参数界面下电压参数减 0.5V, 减到 0.00V 后再按返回 5.00V |

加减功能只在参数界面有效, 清零功能只在计数界面有效; 电压参数范围 0 <= VP <= 5.0.

## 计数规则

计数加 1 的条件在题目里只有一张波形图 (图 5), 扫描件读不出文字; 按米醋工作室的考察重点文档, 它是**下降沿计数**:

- 本次采样电压不大于电压参数, 且上一次采样电压不小于电压参数时, 计数值加 1.
- 只出现上升沿 (由低到高穿越参数) 时计数值不变.

## 存储与参数

- 从参数界面退出时, 把电压参数放大 10 倍写入 AT24C02 内部地址 0, 占用一个字节.
- 设备上电后自动从内部地址 0 读出该数据, 并处理为电压参数 VP.

## LED 指示灯

| 指示灯 | 行为 |
| --- | --- |
| `L1` | VAIN3 小于电压参数的状态持续超过 5 秒时点亮, 否则熄灭 |
| `L2` | 当前计数值为奇数时点亮, 否则熄灭 |
| `L3` | 连续 3 次以上无效按键操作后点亮, 直到出现有效按键操作熄灭 |

## 初始状态

- 数据界面, 计数值 0, `L2` 熄灭.
- 电压参数由 E2PROM 内部地址 0 的数据决定.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 电压数据刷新时间 | <= 0.5s |
| 电压数据采样时间 | <= 0.1s |
| 显示界面切换时间 | <= 0.3s |

## 满分代码

- `src/driver/`: 数码管, 按键, LED, IIC (PCF8591 与 AT24C02) 与初始化驱动.
- `src/user/main.c`: 界面状态机, 电压采样与显示, 下降沿计数, 参数回绕与 E2PROM 存取, 指示灯逻辑.
- `prj/pa11-1.uvproj`: Keil 工程, 输出名为 `pa11-1` (原工程名 `demo`).
- `prj/Objects/pa11-1.hex`: 编译产物, 也是评测脚本的输入.

代码来自米醋工作室的第十一届省赛第一次工程, 采集时只改了工程输出名. 按"参考实现 (已知偏离题目)"看待: 评测脚本查出它的 E2PROM 上电读取没有实现 (详见下节).

## 评测脚本

`judge/full.rhai` 按 OCR 后的题目原文推导, 共 6 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 数据界面以 `U` 显示 AIN3 电压并保留 2 位小数 (3.24V / 1.10V / 4.80V 三点) | 4.2-1, 4.5 |
| 2 | 参数界面 `S16`/`S17` 步进 0.5V 与双向回绕 (0.00V -> 5.00V, 5.00V -> 0.00V) | 4.2-2, 4.3 |
| 3 | 计数界面下降沿计数 (两次下降沿 +1, 只有上升沿不变) 与 `S13` 清零 | 4.2-3, 4.3 |
| 4 | 退出参数界面时把 VP*10 写入地址 0, 上电从地址 0 读回并作为 VP | 4.1, 4.3, 4.5-2 |
| 5 | `L1` 在 VAIN3 小于参数持续超过 5 秒时点亮, 电压回升后熄灭 | 4.4-1 |
| 6 | `L2` 随计数值奇偶变化, `L3` 连续 3 次无效按键后点亮并在有效按键后熄灭 | 4.4-2, 4.4-3 |

运行方式:

```shell
just judge-sample pa11-1
```

当前回归结果: 5 项通过, 1 项失败 (第 4 项, 见下).

## 评测脚本发现的实现问题

- E2PROM 的写入是对的, 上电读取没有实现. 实测: 参数设为 2.50V 后退出参数界面, 地址 0 中确实是 25 (放大 10 倍写入正确); 但重新上电后参数界面仍显示 `P    0.00`, 而题目 4.5-2 要求"设备上电后, 应自动从 E2PROM 内部地址 0 读出数据, 并将该数据处理为电压参数 VP".

## 备注

- 计数界面的提示符段码是 `0x54` (七段数码管上小写 `n` 的画法), 解码表原本没有这个模式, 已在 `crates/core/src/peripherals/display.rs` 补入 `(0x54, 'n')`; 评测脚本按 `^[Nn]\s+\d+$` 接受大小写两种写法.
- 采样实现上电初期的电压跳变会先产生一两次计数, 评测脚本在每个计数检查点先按 `S13` 清零建立基准, 再做下降沿.
- 计数值为 0 时该位数码管熄灭, 评测脚本按整串显示文本提取数字, 不用 `display_number`.
