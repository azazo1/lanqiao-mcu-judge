# PA11-2 第十一届蓝桥杯单片机省赛 (第二次)

题目原文是扫描件: [problem/11 第十一届省赛（第二次）题目_程序题.pdf](problem/11%20第十一届省赛（第二次）题目_程序题.pdf), 已用本地 Apple Vision OCR 转成 [problem/题目OCR文本.txt](problem/题目OCR文本.txt); 同目录另有米醋工作室的界面流转与考察重点两份文档.

同一届省赛的第一次见 [../pa11-1/](../pa11-1/README.md), 两场题目完全不同 (第一次是 AIN3 电压与计数, 本次是 DS18B20 温度与 DAC 输出).

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式跳线 J5 配置为 BTN 按键模式.
- 扩展方式跳线 J13 配置为 IO 模式.

## 功能

- 通过 DS18B20 采集环境温度.
- 数码管显示数据界面与参数界面, 按键切换.
- PCF8591 输出 DAC 模拟电压.
- LED 指示灯做状态指示与报警输出.

## 显示格式

| 界面 | 内容 | 示例 |
| --- | --- | --- |
| 数据界面 | 提示符 `C` + 温度整数 | `C     24` |
| 参数界面 | 提示符 `P` + 温度上限参数 + 温度下限参数 | `P  30 20` |

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 数据界面与参数界面之间切换 |
| `S5` | 参数界面下切换选中的参数 (温度上限 / 温度下限) |
| `S6` | 当前选中的温度参数加 1 摄氏度 |
| `S7` | 当前选中的温度参数减 1 摄氏度 |

- 加减功能仅在参数界面有效.
- 每次从数据界面进入参数界面, 默认选中的是温度下限参数.
- 从参数界面退出时做合理性检查 (上限 >= 下限): 合理则参数生效; 否则恢复进入参数界面之前有效的那组参数, 并点亮 `L4`.

## DAC 输出

| 温度条件 | 输出电压 |
| --- | --- |
| T > 温度上限 | 4.0V |
| 温度下限 <= T <= 温度上限 | 3.0V |
| T < 温度下限 | 2.0V |

## LED 指示灯

| 指示灯 | 行为 |
| --- | --- |
| `L1` | 温度高于温度上限时点亮 |
| `L2` | 温度处于上下限之间时点亮 |
| `L3` | 温度低于温度下限时点亮 |
| `L4` | 出现错误参数设置操作时点亮, 直到下一次正确的参数设置后熄灭 |

## 初始状态

- 数据界面.
- 温度上限参数 30 摄氏度, 温度下限参数 20 摄氏度.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 温度数据刷新时间 | <= 0.5s |
| 显示界面切换时间 | <= 0.3s |
| DAC 模拟电压输出响应时间 | <= 0.3s |

温度参数可调整范围: 0 <= TMAX < 100, 0 <= TMIN < 100.

## 满分代码

- `src/driver/`: 数码管, 按键, LED, IIC (PCF8591), DS18B20 (`onewire`) 与初始化驱动.
- `src/user/main.c`: 界面状态机, 温度采集, 参数选择与加减, 退出参数界面时的合理性检查与回滚, DAC 与指示灯逻辑.
- `prj/pa11-2.uvproj`: Keil 工程, 输出名为 `pa11-2` (原工程名 `demo`).
- `prj/Objects/pa11-2.hex`: 编译产物, 也是评测脚本的输入.

代码来自米醋工作室的第十一届省赛第二次工程, 采集时只改了工程输出名.

## 评测脚本

`judge/full.rhai` 按 OCR 后的题目原文推导, 共 7 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 数据界面整数温度读数, 参数界面默认 30/20, 温度处于区间时 `L2` 亮且 DAC 输出 3.0V | 4.3, 4.5-2, 4.6-2, 4.7 |
| 2 | 参数界面默认选中温度下限, `S5` 切换后 `S6` 改另一个参数; 数据界面下加减无效 | 4.4 |
| 3 | 退出参数界面时上限小于下限则恢复原参数并点亮 `L4`, 下一次正确设置后 `L4` 熄灭 | 4.4-2, 4.6-4 |
| 4 | DAC 三档输出 (4.0V / 3.0V / 2.0V) | 4.2-3, 4.5 |
| 5 | `L1`/`L2`/`L3` 分别对应高于上限, 区间内, 低于下限, 其余指示灯熄灭 | 4.6-1, 4.6-2, 4.6-3 |
| 6 | 参数边界保持在 0-99, 新参数退出参数界面后对 DAC 生效 | 4.2-4, 4.4-2 |
| 7 | 响应时间: 界面切换 <= 0.3s, 温度刷新 <= 0.5s, DAC 跟随 <= 0.3s (实测 60ms / 450ms / 0ms) | 4.2 |

运行方式:

```shell
just judge-sample pa11-2
```

当前回归结果: **7 项全部通过**. 其中第 3 项的实测序列 `[30, 35] -> [30, 20] -> [30, 25]` 说明回滚逻辑正确: 把下限调到 35 (超过上限 30) 后退出, 参数恢复为 30/20; 再进入把下限调到 25 后退出, 参数 30/25 生效.

## 备注

- 采样实现的参数在边界处是回绕而不是夹紧 (下限减到 0 后继续减会绕到 99). 题目只要求"合理设置参数边界范围, 防止出现参数越界", 未明确要求夹紧, 因此评测脚本按 0-99 的范围断言, 不强制取 0.
- DS18B20 的一次转换与刷新约 1 秒, 评测脚本的测量等待量取 2 秒 (题目要求刷新 <= 0.5s, 这里留余量避免读到上一轮数据).
