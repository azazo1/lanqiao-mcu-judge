# NA12 第十二届蓝桥杯单片机国赛

题目原文见 [problem/12 第十二届国赛题目_程序题.pdf](problem/12%20第十二届国赛题目_程序题.pdf) (有文本层直接读取); 同目录另有米醋工作室的界面流转与考察重点文档.

## 竞赛板配置

- IAP15F2K61S2 内部振荡器频率设置为 12MHz.
- 键盘工作模式 J5 配置为 KBD 键盘模式.
- 扩展方式 J13 配置为 IO 模式.

## 功能

设计一个超声波物位计: DS1302 提供时间, 超声波测距, DAC (PCF8591) 输出电压, 数码管显示时间/距离/数据记录/参数四类界面, 按键完成界面切换与参数设定, LED 指示状态.

- 采集模式: 触发模式 (环境光由亮变暗触发一次采集), 定时模式 (RTC 秒值整除采集时间参数时触发一次采集).
- 距离参数附近报警: 定时模式下连续 3 次测距落在距离参数 ±5cm 内时 `L5` 点亮.
- 数据记录: 统计上电后所有采集结果的最大值, 最小值与平均值.

## 显示格式

| 界面 | 内容 | 示例 |
| --- | --- | --- |
| 时间数据显示 | 时, 分, 秒各 2 位, `-` 分隔 | `20-20-01` |
| 距离数据显示 | 标识 `L` + 模式标识 (触发 `C` / 定时 `F`) + 3 位距离 | `LC    26` |
| 数据记录显示 | 标识 `H` + 类型标识 + 4 位数据 | `H=    39` |
| 采集时间参数 | 标识 `P1` + 采集时间 (2 位补 0) | `P1    02` |
| 距离参数 | 标识 `P2` + 距离参数 (2 位补 0) | `P2    20` |

- 数据记录的类型标识使用数码管的 a, g, d 三个段分别表示最大值, 平均值, 最小值; 本仓库的段码解码表把它们映射为 `=`, `-`, `_`.
- 最大值与最小值为整数, 平均值保留 1 位小数; 采集时间参数取值 2, 3, 5, 7, 9 秒; 距离参数范围 10-80cm.

## 按键

| 按键 | 功能 |
| --- | --- |
| `S4` | 切换数据显示界面与参数设置界面 |
| `S5` | 数据显示界面下切换 时间/距离/数据记录; 参数界面下切换 采集时间/距离参数 |
| `S8` | 距离界面下切换 触发模式/定时模式; 数据记录界面下按 最大值/最小值/平均值 顺序切换 |
| `S9` | 采集时间参数按 2/3/5/7/9 循环; 距离参数加 10 |

界面切换要求: 每次进入参数界面默认采集时间设置, 回到数据显示界面默认时间数据显示, 每次进入数据记录界面默认显示最大值; 参数在退出参数界面后生效.

## DAC 输出

输出电压与最近一次测距结果成直线: 10cm 对应 1.0V, 80cm 对应 5.0V (10cm 以下保持 1.0V).

## LED 指示灯

| 指示灯 | 行为 |
| --- | --- |
| `L1` | 时间数据显示界面 |
| `L2` | 距离数据显示界面 |
| `L3` | 数据记录显示界面 |
| `L4` | 触发模式 |
| `L5` | 定时模式下连续 3 次测距在距离参数 ±5cm 内 |
| `L6` | 环境光为亮 |

## 初始状态

- 时间数据显示界面, 触发模式.
- 采集时间参数 2s, 距离参数 20cm, 每次上电重置为默认值.

## 性能要求

| 项目 | 要求 |
| --- | --- |
| 界面切换时间 | <= 0.2s |
| 按键动作响应时间 | <= 0.2s |
| 测距范围 | >= 80cm |
| 超声波测距精度 | <= ±4cm |
| DAC 输出电压误差 | <= ±0.3V |

## 满分代码

- `src/driver/`: 数码管, 按键, LED, IIC (PCF8591), DS1302, 超声波 (`ultrasound`), 滤波 (`filtering`) 与初始化驱动.
- `src/user/main.c`: 界面状态机, 采集模式与触发条件, 数据记录统计, DAC 换算与指示灯逻辑.
- `prj/na12.uvproj`: Keil 工程, 输出名为 `na12` (原工程名 `demo`).
- `prj/Objects/na12.hex`: 编译产物, 也是评测脚本的输入.

代码来自米醋工作室的第十二届国赛工程, 采集时只改了工程输出名.

## 评测脚本

`judge/full.rhai` 按题目原文推导, 共 8 个评测点:

| 序号 | 评测点 | 题目出处 |
| --- | --- | --- |
| 1 | 时间数据显示界面, 触发模式与光亮指示, 参数默认 2s/20cm | 4.3-1, 4.7, 4.8 |
| 2 | 触发模式下光由亮变暗采集一次, 距离界面显示 `LC` 与距离 | 4.3-2, 4.6-2 |
| 3 | `S8` 切定时模式后按秒值整除采集, DAC 输出与距离成直线 | 4.5, 4.6-1, 4.7 |
| 4 | 数据记录界面按最大值/最小值/平均值切换, 标识为 a/g/d 段, 三个数值关系正确 | 4.3-3, 4.4 |
| 5 | 采集时间参数循环 2/3/5/7/9, 距离参数加 10 且不越界, 进入参数界面默认采集时间 | 4.3-4, 4.4 |
| 6 | 定时模式下连续 3 次测距在距离参数 ±5cm 内时 `L5` 点亮, 远离后熄灭 | 4.3-4, 4.7-5 |
| 7 | DAC 三点: 10cm 输出 1.0V, 45cm 约 3.0V, 80cm 输出 5.0V | 4.5 |
| 8 | 响应时间: 按键动作响应 <= 0.2s, 界面切换 <= 0.2s (实测均为 0ms) | 4.2 |

运行方式:

```shell
just judge-sample na12
```

当前回归结果: 7 项通过, 1 项失败 (第 6 项, 见下).

## 评测脚本发现的实现问题

- 定时模式下的距离附近报警 `L5` 没有实现 (第 6 项). 复核时把测距结果放在距离参数的中心位置, 排除边界噪声的影响: 距离参数调到 40cm, 测距结果稳定为 39cm (落在 40±5cm 内), 处于定时模式 (界面显示 `LF    39`), 等待 8 秒 (采集时间参数 2s, 覆盖 4 次整除触发) 后 `L5` 仍为灭. 按题目 4.7-5, 定时模式下"连续"测量到 3 次距离数据在距离参数 ±5cm 内时 `L5` 应点亮. 另外单独用探针观察了 12 秒, 期间 `L5` 始终为灭.

其余实测与题目一致: 时间界面与时间读数, 触发模式 (光由亮变暗) 采集, 定时模式按秒值整除采集, 距离显示与 `L2`, 数据记录的最大/最小/平均值与 a/g/d 段标识, 参数循环与不越界, 指示灯 `L1`/`L3`/`L4`/`L6`, DAC 三点线性.

## 备注

- 段码解码表为本次新增了单段映射: a 段 `0x01` 解码为 `=`, d 段 `0x08` 解码为 `_` (g 段 `0x40` 原本就解码为 `-`), 否则数据记录界面的三个类型标识都会显示为未知字符. 已同步更新 `docs/judge-script-manual.md`, 并跑了段码相关单测 (10 passed).
- 触发模式下的采集需要环境光由亮变暗, 评测脚本用 4.0V 与 0.5V 两个电平模拟.
- 采样实现的距离参数在边界处是回绕 (80 再加 10 变 10), 题目只要求不越界, 评测脚本按 10-80 范围断言.
- 评测脚本在读取测距结果时先快照显示文本再断言, 避免断言时读到后续步骤的显示.
